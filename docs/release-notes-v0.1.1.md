# TextFlow v0.1.1

## Novedades

- **Ordenar los comandos de un grupo.** En la lista de un grupo, arrastra un comando a su nuevo sitio, usa «Subir», «Bajar», «Al principio» o «Al final» con clic derecho, o pulsa `Alt+↑` / `Alt+↓`. El menú del grupo (`lc`, etc.) muestra los comandos en ese orden.
- **Varias bibliotecas de aText.** Inicio › Más › «Añadir otra biblioteca aText…» añade uno o varios backups `.atext` a tu biblioteca sin borrar nada:
  - cada archivo entra como un grupo nuevo al final, con su nombre;
  - un comando que ya tienes se actualiza donde esté, sin duplicarse;
  - si un comando nuevo usa una abreviatura que ya existe, se avisa y sigue saliendo el que ya tenías;
  - antes se guarda una copia de seguridad, como en cada importación.

  «Importar desde aText…» sigue reemplazando la biblioteca entera.

## Actualizar

TextFlow se actualiza solo y avisa en la bandeja. También puedes buscar la actualización en Configuración → Acerca de TextFlow.
